# GlobalShopCo — Pet SKU Economics Capture Sheet — 2026-09-04

## Purpose
Provide a decision-ready structure for converting authenticated supplier evidence into SKU-level launch economics. This is a capture template, not evidence itself.

## Required fields per SKU

| Field | Required evidence |
|---|---|
| Supplier | Authenticated supplier/account evidence |
| Supplier SKU | Supplier catalogue/feed |
| Product/variant | Supplier source |
| Stock status | Current supplier/feed evidence |
| Supplier cost | Authenticated trade price |
| Supplier freight | Authenticated destination/freight evidence |
| Customer price | Proposed retail price |
| Delivery promise | Supplier/carrier evidence |
| Free-delivery cost | Actual or conservative model |
| Payment/transaction cost | Current provider rate/model |
| Returns/refunds | Supplier terms + assumed exposure |
| Damage/replacement exposure | Supplier terms + conservative assumption |
| Contribution before acquisition | Calculated |
| CAC allowance | Scenario assumption until measured |
| Contribution after CAC | Calculated scenario |
| Compliance/customer-trust checks | Primary-source evidence where applicable |
| Decision | Hold / Evidence Complete / Economically Viable / First-Vertical Candidate |

## Minimum scenario model

### Conservative
Use higher plausible delivery/returns exposure and no unproven upsell or repeat-purchase benefit.

### Base
Use authenticated supplier cost/freight and reasonable observed operating assumptions.

### Upside
May include bundle/repeat benefits only when explicitly labelled as assumptions or subsequently measured.

## Decision rule

A SKU should not be called economically viable merely because gross markup is positive. The contribution test must account for customer price, supplier cost, delivery/free-delivery treatment, payment/transaction costs and a conservative allowance for returns/damage/operating exposure.

If acquisition cost is unknown, record contribution before CAC and mark post-CAC profitability **UNKNOWN** rather than inventing a CAC.

## First test set

Capture 5–10 SKUs across promising pet-accessory subcategories. Prefer products that are low-risk, simple to explain, parcel-friendly, supported by reliable stock/tracking and suitable for bundles or repeat purchasing where evidence supports it.

## Evidence rule

Supplier request packs, public retail prices, supplier-reported margins and generic category margins do not populate authenticated supplier-cost fields. Every material input needs a source and checked date.
